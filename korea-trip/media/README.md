# Korea Trip 2026 — Media / Files

## 📁 โฟลเดอร์เก็บไฟล์
```
korea-trip/media/
├── photos/          ← ภาพถ่าย/ภาพสแนนชอต/รายการ
├── documents/       ← ไฟล์ PDF/ตั๋ว/ใบเสร็จ/เอกสาร
└── screenshots/     ← สกรีนชอตจากโซเชียล/แผนที่/เว็บ
```

## 📝 วิธีใช้งาน
1. วางไฟล์ตรงตามประเภท
2. ตั้งชื่อไฟล์ชัดเจน: `YYYYMMDD-รายละเอียด.jpg`
3. เก็บต้นฉบับ ไม่ต้องบีบอัด
4. เก็บ link ไฟล์นี้ใน `itinerary.md` หรือ `raw/*.md` ได้
